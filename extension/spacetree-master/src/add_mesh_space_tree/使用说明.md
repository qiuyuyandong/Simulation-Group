# SCA Tree Generator 0.2.17

已验证环境：Blender 5.2.1 LTS。Blender 5.0 不受此版本支持；其他版本未实际验证。

## 安装与替换旧版

1. 保存 Blender 中的工作。
2. 打开编辑 → 偏好设置 → 插件，找到并禁用旧的 SCA Tree Generator。
3. 从该页面右上角菜单选择“从磁盘安装”，选择 `SCA_Tree_Generator_0.2.17_Blender_5.2.1.zip`。安装时保留 ZIP 的完整目录结构。
4. 重启 Blender，在插件页启用 SCA Tree Generator，并确认版本显示为 0.2.17。
5. 在 3D 视图的添加 → 网格 → Add Tree to Scene 中使用插件。

插件默认生成树的骨架；需要实体树干时，在生成参数中关闭 No Modifiers，选择皮肤方式。添加叶片时开启 Add Leaves & Objects 并选择叶片预设。

## 使用现有场景脚本

继续使用原来的 `bpy.ops.mesh.sca_tree(...)` 接口。
新版脚本另外可向 `SCA(..., initial_skeleton=...)` 传入由位置和父索引组成的骨架，之后由原算法生长细枝；不传时保持原行为。每个节点至多两个子节点，父节点必须先出现。
Kill Distance、Influence Range是实际Blender单位，不是节间倍数。`scale`是枝条半径因子，标识保留；新版场景脚本通过主干直径与逐级变细参数控制实际尺寸。
树皮材质可指定 `barkMaterial='BarkBetter1.1'`。该标识来自材质库，重复运行后仍保持稳定。

只分享本插件时，同伴仍需另行获得场景脚本所需的水果模型、叶片贴图和 HDRI；这些不是插件本身的依赖。

## 分享与复用

- 分享整个安装 ZIP 即可，插件代码、材质库、4 张内嵌贴图及纹理副本已包含在内。
- 路径以安装后的插件目录为基准；不要求相同用户名、盘符或安装目录。
- 树皮材质和粒子预设使用原始库标识作为选项，实际数据块被自动改名不会改变调用接口。
- 不需要安装 Python、第三方 Python 库或旧的 C 加速模块；使用 Blender 自带 Python。
- 大型树使用纯 Python 算法生成，运行时间可能较长。随机参数和硬件差异可能影响结果，未承诺逐像素相同。
